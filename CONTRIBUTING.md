# Contributing

Thank you for looking. Two rules for now:

**Issues are always welcome.** Bug reports, wrong numbers, confusing
screens, missing bodies, documentation that does not match what the code
does: please open an issue.

**Outside code contributions are not being accepted at the moment.** Pull
requests from outside the project will be closed without review. That is
not a judgement on the change: the project is early, its licensing and
direction are still settling, and reviewing code properly takes time it
does not have yet. If you have a fix, describe it in an issue; a clear
description of the problem is often the more useful half anyway. This may
change later, and this file will say so when it does.

## A good issue

- **What you did, what you expected, what happened.** For a wrong total,
  the credential, the entries involved (invented ones are fine) and the
  number you expected.
- **Rule corrections:** if a body's cap, minimum, cycle or fee in
  `bodies.yaml` is wrong or out of date, link the body's own published page
  that says so. Rules here are only changed against a primary source, and
  the file records which source and when.
- **A new body's submission form:** the form's field labels in order, and
  where you saw them. See `packetmaps/README.md` for what a mapping needs.
- **Never include** your real CPE history, certificates, member numbers,
  portal logins, bot tokens or anything else personal. Fictional examples
  are all an issue needs.

## Security problems

Do not open a public issue for a vulnerability. See [SECURITY.md](SECURITY.md).
