# Registrar v1.2.2

Released 2026-10-22.

Fixes from a review of v1.2.1, mostly about data you import and the
sample data. Finding numbers (F1 to F13) are the reviewer's.

## What's fixed

- **Removing the sample keeps your changes (F1).** If you loaded the sample
  data and then changed one of the credentials it set up (a start date, a
  carry-over), "Remove sample data" used to undo it anyway. Now it undoes
  only the settings that are still exactly as the sample left them, and
  tells you how many of yours it kept. Importing a backup made while the
  sample was loaded no longer brings the sample's bookkeeping with it, so
  removing sample activities afterwards never touches your settings.
- **Imports are checked more strictly (F3, F4, F5).** A backup file whose
  fields have the wrong type is refused with a message naming the field,
  evidence file names are cleaned the same way as uploads, and an embedded
  file over 15 MB is refused. Packet zips never contain a file name with a
  folder path in it.
- **Big or slow files (F5).** A file over 15 MB is refused straight away,
  before the app reads it. Reading a scanned certificate stops after 60
  seconds with "OCR timed out" instead of running on.
- **Your own API key (F2, F8, F10).** Requests to Anthropic use the API
  version every account accepts. The key field asks your browser and
  password manager not to offer to save it. The privacy page now says
  that a model on your own machine is reached over plain HTTP.
- **Self-hosting guide (F6, F7).** The demo-data steps no longer start by
  deleting your data: the demo runs in its own container. The settings
  table lists `REGISTRAR_ALLOWED_HOSTS`, which you need if you browse to a
  VPN address or a name.
- **The website (F9).** Unknown addresses get a proper "Page not found"
  page, and every page, that one included, runs no scripts.

## Also in this release

- The footers of the landing page and the privacy page say "Built with

- ceu.tools is also served at cpe.insiderthreatanalyst.com and mirrored on
